# White Cup — результат redesign, 14 сентября 2026

Основная композиция первого экрана сохранена. Новая цепочка страницы: первый экран → короткое знакомство → меню со scroll-snap без автопрокрутки → атмосфера с реальными фотографиями → две точки → контакты.

Удалены старые перекрывающие polish CSS, тесты прежних визуальных контрактов и лишние блоки. React, TypeScript и Vite сохранены; новые зависимости не добавлялись.

Адреса и телефон сверены по [карточке White Cup](https://yandex.com/maps/org/white_cup/19381755919/) и [второй карточке White Cup](https://yandex.com/maps/org/white_cup/193710716150/). Иллюстрации блюд помечены как иллюстрации; часы работы и цены не придуманы.

Проверено:

- 12 файлов и 30 тестов;
- production build: CSS 42.47 KB (gzip 9.11 KB), JS 249.81 KB (gzip 73.62 KB);
- браузерные viewport 1920×1080, 390×844 и 320×568, без горизонтального переполнения;
- управление каруселью с клавиатуры, мобильное меню, Escape, переходы к разделам и режим уменьшенного движения;
- мобильные размеры проверены во встроенном Chromium; реального Safari/iOS-теста не было.

Независимое визуальное ревью существенных замечаний не выявило.

Опубликованная версия: [kaigo.space/site/whitecup](https://kaigo.space/site/whitecup/). Проверены HTTP 200, gzip CSS/JS, совпадение SHA-256 публичного index с локальной сборкой (`a18c461c902683420ebfbe9a532bb3c5d00fff719146b20ed07a88f8a2523e2d`) и 110 файлов server manifest. Резервная версия сохранена.
