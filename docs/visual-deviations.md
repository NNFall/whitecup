## Источники медиа

- Документальные изображения — только локально сохранённые и визуально проверенные публичные кадры из Yandex Maps; они распределены по сценам как интерьер/атмосфера/локация.
- Нормальный hero-path использует `hero-clean-base-v2-*.webp` (ImageGen reference edit), `hero-bagel-plate-reference-edit-*.webp` (ImageGen edit + deterministic chroma alpha), существующий coffee WebP, `hero-doodles-exact.png`, `hero-route-cup-1672.webp`, `hero-skyline-exact.png`, reference logo crop и `hero-underline-reference-extract-tight.webp`. Это отдельные decorative reference-art, не documentary evidence. Ранние POC/Remove Background experiments удалены из `public/media`; authoring-файлы активных слоёв сохранены только в `docs/reference/assets/`.
- About использует отдельный responsive foreground `about-pastry-plate-reference-edit-v2-*.webp`, созданный через Image Generation Skill по supplied About-reference. Полная тарелка сохранена в alpha-слое; она — editorial reference-art, не подтверждение блюда или меню White Cup.
- `Remove Background Local` был действительно прогнан для нового bagel/plate edit, но его результат отброшен: он потерял белую тарелку. В production применён контролируемый chroma alpha; проверочные authoring PNG оставлены только в `docs/reference/assets/`.
- Меню загружает только production WebP: responsive-пару `menu-clean-base-*.webp` и responsive-пары `menu-{cappuccino,bagel,waffle,syrniki,cheesecake}-*.webp`. Исходные authoring PNG использовались как локальные промежуточные файлы генерации и намеренно не публикуются; provenance каждого runtime-слоя зафиксирован в `src/data/media.ts`.
- VK остаётся внешней ссылкой, но его недоступные для проверки публикации не превращаются в факты лендинга.
